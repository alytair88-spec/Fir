# Hungary City Map

Кросплатформний мобільний додаток (iOS + Android): обираєте будь-яке місто чи село Угорщини, і на карті з'являються надавачі послуг та магазини — шиномонтажі, автосервіси, автошколи, стоматології, фітнес-клуби, магазини взуття й одягу, бари, ресторани тощо. Їх можна фільтрувати за категоріями.

- **Гості (без облікового запису)**: переглядають карту, фільтрують за категорією, шукають за назвою чи адресою, відкривають картку об'єкта (телефон, сайт, графік, маршрут).
- **Власники бізнесу (з обліковим записом)**: реєструються за email, додають один чи кілька об'єктів, редагують їх, вказують точку на карті, приховують або видаляють.

Інтерфейс доступний українською, угорською та англійською (мова визначається з налаштувань пристрою, її можна змінити у вкладці «Мій бізнес»).

## Стек

| Частина | Технологія |
| --- | --- |
| Мобільний додаток | [Expo](https://expo.dev) SDK 57 + React Native + TypeScript, навігація Expo Router |
| Карта | `react-native-maps` (Apple Maps на iOS, Google Maps на Android) |
| Бекенд | [Supabase](https://supabase.com): Postgres, автентифікація, Row Level Security |
| Пошук міст і адрес | OpenStreetMap Nominatim |

## Структура

```
mobile/                       Expo-додаток
  src/app/                    екрани (Expo Router)
    (tabs)/index.tsx          карта міста + фільтр категорій
    (tabs)/search.tsx         список/пошук об'єктів у місті
    (tabs)/account.tsx        вхід/реєстрація, «мої об'єкти», мова
    city-picker.tsx           вибір міста (популярні + пошук будь-якого населеного пункту)
    business/[id].tsx         картка об'єкта
    owner/edit.tsx            додавання/редагування об'єкта власником
  src/constants/              категорії, міста, кольори
  src/context/                стан: мова, місто, категорія; автентифікація
  src/lib/                    Supabase-клієнт, API, геокодування, переклади, демо-дані
supabase/
  migrations/0001_init.sql    таблиці, індекси, правила доступу (RLS)
  seed.sql                    демо-об'єкти (необов'язково)
```

## Швидкий старт (демо-режим, без бекенду)

```bash
cd mobile
npm install
npx expo start
```

Відскануйте QR-код у застосунку Expo Go (Android/iOS). Без налаштованого Supabase додаток працює в демо-режимі: показує кілька тестових об'єктів у Будапешті, Дебрецені та Сегеді, а реєстрація бізнесу вимкнена.

## Підключення бекенду (Supabase)

1. Створіть проєкт на [supabase.com](https://supabase.com).
2. У **SQL Editor** виконайте `supabase/migrations/0001_init.sql`, а за бажання — `supabase/seed.sql`.
3. Скопіюйте `mobile/.env.example` у `mobile/.env.local` і вкажіть `EXPO_PUBLIC_SUPABASE_URL` та `EXPO_PUBLIC_SUPABASE_ANON_KEY` (Project Settings → API).
4. Перезапустіть `npx expo start`.

За замовчуванням Supabase вимагає підтвердження email після реєстрації: користувач отримає лист, після чого зможе увійти. Вимкнути це можна в Authentication → Providers → Email.

### Правила доступу (RLS)

- Будь-хто, навіть без входу, бачить усі **опубліковані** об'єкти.
- Власник бачить і свої приховані об'єкти.
- Створювати об'єкти можна лише від свого імені; змінювати й видаляти — лише свої.
- Координати повинні бути в межах Угорщини (перевірка в базі даних).

## Збірка для магазинів застосунків

Збірка йде через [EAS Build](https://docs.expo.dev/build/introduction/) у хмарі (Xcode/Android Studio не потрібні):

```bash
cd mobile
npx eas-cli@latest build --platform android   # або ios / all
```

- Для Android потрібен ключ **Maps SDK for Android** з Google Cloud: `GOOGLE_MAPS_ANDROID_API_KEY` (додайте як змінну середовища EAS).
- На iOS за замовчуванням використовуються Apple Maps, ключ не потрібен.
- Перед публікацією змініть `bundleIdentifier` / `package` у `mobile/app.config.ts` (зараз `com.example.hungarycitymap`).

## Що можна додати далі

- Фото та логотипи об'єктів (Supabase Storage).
- Відгуки й рейтинги від користувачів.
- Кластеризацію міток на карті для великих міст.
- Модерацію нових об'єктів перед публікацією.
- Власний або платний геокодер замість публічного Nominatim (у нього обмеження: ~1 запит/с).
